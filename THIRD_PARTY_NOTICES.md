`face_landmarker.task` is a MediaPipe model file. It is **not committed** to this repository,
and this project does not redistribute it. To run extraction, download the model yourself
and place it at `models/mediapipe/face_landmarker.task`.

Before you redistribute the model file, check its license on the official MediaPipe model
page and follow the terms stated there. The license of this model file has not been verified
